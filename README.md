# Perfect Pitch
A Vue application to help you to review your resumes. Built with Vue 3 and Tailwind CSS.

[![GitHub](https://img.shields.io/badge/GitHub-100000?style=for-the-badge&logo=github&logoColor=white)](https://github.com/justinmccarthy/perfect-pitch)

## Features
- Review your resumes with ease by AI
- Upload your resumes in PDF or DOCX format
- Get instant feedback on your resume

## Tech Stack

- Frontend
    - Vue 3
    - Tailwind CSS
- Backend
    - Node.js
    - Express.js
    - MongoDB
    - Typescript
    - Gemini AI
